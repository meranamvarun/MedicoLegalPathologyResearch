# Outputs directory

Store generated study outputs here:

- `tables/`: descriptive tables, coding summaries, and outcome tables.
- `figures/`: plots and diagrams.
- `reports/`: interim reports, manuscript exports, and appendices.
- `literature/`: literature review summaries, bibliography exports, citation-lead tables, and thematic synthesis outputs.

Generated outputs should identify the script or notebook that created them and the dataset version used.
